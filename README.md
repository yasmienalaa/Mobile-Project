
# E-Learning Android App

An Android e-learning application built with **Kotlin**, **XML**, and **Room Database** to help students explore courses, enroll in lessons, take quizzes, and track their learning progress. The app also includes admin features for managing educational content.

## Planned Features

- User registration, login, and profile management
- Course browsing and enrollment
- Lessons and learning progress tracking
- Quizzes and answer history
- Admin management of courses and lessons
- Local data storage with Room Database
